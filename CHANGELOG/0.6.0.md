## Breaking changes

- `kindtks install` is gone. Install and upgrade with the one-liner below; it needs only Docker and bash on the host.
- Hosts that installed 0.5.x through `docker run … install` may have root-owned files left in `~/.local/share/kindtks`. If the installer cannot remove them, run `sudo rm -rf ~/.local/share/kindtks` and install again.
- `kindtks create` now checks registry credentials before creating anything. Rejected credentials from the config file stop `create`; credentials that cannot be checked (registry unreachable from the host) only warn. `--skip-auth-check` turns the check off.

## New

- **Bundled tools.** The image carries pinned kind v0.33.0, kubectl v1.33.1 and helm v3.21.0; kindtks always runs profiles with them, and the installer offers them where yours are missing or older. Air-gapped: push the image to your registry and run the same one-liner with that reference.
- **`auth: prompt`.** `registries.<registry>.auth: prompt` asks for the username and password on the terminal at `kindtks create` (hidden password, reuse across registries, up to three attempts), so credentials stay out of config files.
- **No more `openssl`/`envsubst` on the host** for the gen1 profile.
