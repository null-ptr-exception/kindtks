## New

- **macOS on Apple Silicon.** The same one-liner installs kindtks on macOS, with [Colima](https://github.com/abiosoft/colima) as the Docker runtime (`brew install colima docker`, then `colima start --cpu 4 --memory 4`). Intel Macs are not supported. On macOS, `*.kindtks.localhost` names resolve only in browsers and curl; see the README's macOS section.
- **Multi-arch image.** The image is published for `linux/amd64` and `linux/arm64`, and also carries the macOS arm64 binaries of kindtks, kind, kubectl and helm.

## Changes

- Releases come from the `VERSION` file: a commit that sets it to a release version publishes the image and creates the tag, with notes from `CHANGELOG/<version>.md`. `-rcN` releases no longer move the `latest` image tag.
