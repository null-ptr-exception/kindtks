## New

- **gen1-rootless profile.** gen1 for rootless Docker: the same cluster without Cilium, which does not run under rootless Docker. kind's default CNI (kindnet) gives pod networking, and [kube-network-policies](https://github.com/kubernetes-sigs/kube-network-policies) enforces NetworkPolicy. See `kindtks help gen1-rootless` for the host requirements.
